
# AI POWERED SIGN LANGUAGE TO TEXT AND SPEECH

## Project Overview

This project focuses on recognizing American Sign Language
(ASL) hand gestures and converting them into text and speech
to support communication for deaf and speech-impaired users.

The system uses Vision Transformer-based deep learning
architectures to classify hand gesture images and generate
corresponding text and speech outputs.

## Objectives

- Recognize ASL hand gesture images.
- Convert recognized gestures into text.
- Generate speech output from recognized text.
- Compare different Vision Transformer architectures.
- Explore AI-based solutions for accessible communication.

## Technologies Used

- Python
- Deep Learning
- Computer Vision
- Google Colab
- Vision Transformer (ViT-Base)
- Swin Transformer (Swin-Tiny)
- Data-efficient Image Transformer (DeiT-Tiny)

## Models Implemented

1. ViT-Base
2. Swin-Tiny
3. DeiT-Tiny

## Dataset

The project uses an existing ASL image dataset
obtained from Kaggle.

All input images are resized to 224 x 224 pixels
for model processing.

## Model Performance

The following are the testing accuracies obtained
in our project:

| Model | Testing Accuracy |
|-------|------------------|
| ViT-Base | 99.97% |
| Swin-Tiny | 99.99% |
| DeiT-Tiny | 70.95% |

## System Workflow

1. Input ASL hand gesture image.
2. Image preprocessing and resizing.
3. Gesture classification using trained models.
4. Recognized gesture converted into text.
5. Text converted into speech output.

## Application Outputs

The system provides:
- Recognized text output.
- Speech output.
